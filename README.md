# マンホールカード 共通ID台帳

**Manhole Card Common ID Registry** — マンホールカード収集アプリ間で取得状況を交換する際に、共通のカードIDを参照できるようにするための、非公式の基本ID一覧です。

**共同整備・相互運用性検証：public cardigan / blue25000**

**台帳バージョン：v1.0.0（初回正式公開版）**

> 初版は public cardigan が anythingsearch.info の管理データを基に作成し、blue25000 との照合・相互運用性検証を通じて整備しています。GKP・マンホールカード発行団体による公式登録簿や認定資料ではありません。

## 収録内容

- [`data/basic_ids.csv`](data/basic_ids.csv)：UTF-8、ヘッダー `basic_id`、**1,317件**、1行1種類
- [`data/card_reference.csv`](data/card_reference.csv)：基本ID・都道府県・カード名・発行弾・カード詳細URLの**5列照合用一覧**（1,317件）
- [`docs/exchange-format-v1.md`](docs/exchange-format-v1.md)：第三者のアプリ開発者向け**共通JSON交換仕様（基本ID版）**
- 整備元：anythingsearch.info の[マンホールカードアプリ用データAPI](https://anythingsearch.info/wp-json/mhc-app/v1/map)を基に、共同照合・相互運用性検証を実施
- 基本IDを重複なく整理し、書式や一覧内の重複を検査（カード現物との全件照合や将来の最新性を保証するものではありません）

CSV例：

```csv
basic_id
00-101-A001
00-102-A001
00-102-B001
01-100-A001
```

## IDの扱い

- 基本IDの例：`13-100-A001`、`KH-001-A001`
- 英字の大文字と数字のゼロ埋めを保持します。
- **同じカードが複数の配布地点で配られていても、基本IDは1件**です。
- 言語・印刷版などを区別する版別ID（例：`13-100-A001-ja-a01`）は現時点では登録していません。推測では追加しません。
- 配布終了や在庫切れになっただけで、既存のIDを自動削除しません。誤登録の訂正は変更履歴で追跡します。

### 旧番号・新番号について

小樽市 `01-203-A001` / `01-203-A002`、豊富町 `01-516-A001` / `01-516-A002`、尾張旭市 `23-226-A001` / `23-226-A002` は、それぞれ台帳内に両方の基本IDを残しています。これらを同一カードとして扱うかどうかや、交換ファイルへの書き出し・取り込み時の正規化は各アプリ側の仕様で定めてください。

## アプリ間の取得状況交換との関係

共通JSON交換形式（`format: manhole-card-collection-exchange`, `version: 1`）では、利用者が取得したカードの基本IDを `cards` 配列に格納します。

```json
{"format":"manhole-card-collection-exchange","version":1,"cards":["13-100-A001"]}
```

このリポジトリに利用者の取得状況は**含まれません**。各アプリの内部IDと基本IDの変換・取得済み状態の取り込みは、それぞれのアプリが担当します。

**重要：** この一覧にまだ載っていないIDを、交換ファイルのインポート時に無条件で拒否するための許可リスト（ホワイトリスト）としては使わないでください。データ更新時の追加・修正があり得ます。

台帳のリリース番号（例：`v1.0.0`）と交換JSONの `version: 1` は別のものです。

第三者アプリの実装では、[共通JSON交換仕様（基本ID版 v1）](docs/exchange-format-v1.md) を参照してください。

## 更新・訂正

新規カードやID誤りを見つけた場合は、対象IDと確認できる根拠を添えてGitHubのIssueでお知らせください。訂正の確定は管理者が行います。第三者アプリ固有の内部IDとの対応表は、この台帳に含めません。

## 公開範囲と利用条件

このリポジトリには基本ID一覧、照合用の都道府県・カード名・発行弾・個別ページURL、交換仕様の文書を含めます。カード画像・位置情報・配布施設の詳細・取得履歴・内部レビュー資料は収録しません。

## 共同整備・相互運用性検証

- **public cardigan**：初版の基本ID一覧の作成、anythingsearch.info の管理データとの照合・訂正
