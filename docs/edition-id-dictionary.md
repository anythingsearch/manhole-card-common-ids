# 版別ID辞書（基本IDとは別の照合辞書）

このファイルは、マンホールカード共通ID台帳に掲載されている基本IDに対し、言語や版の種類を区別するための **版別ID辞書** を説明します。非公式のアプリ間照合用資料であり、カードの発行済み・配布状況・在庫・取得枚数を表すデータではありません。

## ファイル

- `data/edition_ids.csv`：版別IDだけを収録する1列CSV（4,602件）。ヘッダーは `edition_id`。
- `data/edition_id_review.csv`：基本ID・言語・版区分・名称を含む7列の照合用CSV（4,602件）。発行状況を表す列は設けません。
- `data/basic_ids.csv`：既存の基本ID辞書（2,287件）。変更なし。

## IDの構造

`基本ID-言語コード-版区分＋連番` を使用します。

例：

- `13-100-G001-ja-a01`：日本語・通常版・01
- `13-100-G001-en-a01`：英語・通常版・01
- `13-100-G001-ja-b01`：日本語・特別版・01
- `KH-001-A001-km-a01`：クメール語・通常版・01

基本IDは大文字を保持し、言語コード（`ja`, `en`, `km`）と版区分（`a`, `b`）は小文字とします。`a` は通常版、`b` は特別版、末尾の2桁は識別連番です。

## 登録範囲

| 区分 | 件数 | 説明 |
| --- | ---: | --- |
| `ja-a01` | 2,287 | 全基本IDに一律先行登録 |
| `en-a01` | 2,287 | 全基本IDに一律先行登録 |
| `ja-b01` | 27 | 東京都の特別版第1弾12種類・第2弾15種類を個別登録 |
| `km-a01` | 1 | カンボジア・シェムリアップ市の個別登録 |
| **合計** | **4,602** | 版別ID重複なし |

日本語・英語通常版は、**まだカードが発行されていない基本IDについても一律先行登録**しています。収録されているだけで実在する言語版があるとは判断しないでください。特別版の一律先行登録は行いません。

韓国語 `ko`・中国語 `zh`・`a02` 以降・その他の特別版は、今回一律生成していません。今後必要になった場合に個別に確認します。

## 現行のアプリ間交換との関係

現行の交換JSON `format: manhole-card-collection-exchange`, `version: 1` は **基本ID** での取得状況交換を規定しています。本版別ID辞書の公開によって交換JSONの形式や共通必須要件は変わりません。版別IDを受信して基本IDに集約する処理はアプリ独自の追加対応として可能ですが、全アプリに要求するものではなく、版別情報の往復保持を保証しません。

比田様の「マンホールカードマップ」Android版では、東京都特別版27件の `-ja-b01` 付きIDを交換JSON `version: 1` に入れて読み込む試験が成功しました。27件とも対応する基本IDの取得済みに反映され、重複読み込みや既存ピン色の保持も問題ありませんでした。一方、取得状況の保存時には基本IDのみを出力するため、言語・版の区別は保持されません。この挙動は同アプリでの確認結果であり、すべてのアプリに共通の必須仕様ではありません。

基本IDのみから日本語通常版や特別版を勝手に推定しないでください。取得済み記録の追加のみを行い、既存取得記録を削除しないという安全方針は引き続き重要です。

## 根拠と注意事項

- 基本IDは台帳 v1.1.0（2,287件、コミット `03060cd8d278d57f03d55c8cac4bb30fe7a3c609`）を基準とします。
- 東京都特別版27種類の元データは、2026年10月11日時点のanythingsearchアプリ用データおよび東京都公式公表（2020年・2021年）により照合したものです。
- 東京都公式参考資料： https://www.spt.metro.tokyo.lg.jp/tosei/hodohappyo/press/2020/10/28/11.html および https://www.spt.metro.tokyo.lg.jp/tosei/hodohappyo/press/2021/10/29/09.html
- IDと具体的な発行品の関係について、カード現物との全件照合は実施していません。
- カードの発行・配布・在庫・取得済み状況は各アプリ側が管理します。
